HOW TO UPDATE GITHUB
1. Upload and replace index.html, styles.css, and script.js.
2. Keep all JPG files in the main repository folder.
3. Commit the changes.
4. Wait 1–3 minutes and refresh the live site.

The email application uses the visitor's own email app. For a form that sends silently without opening an email app, connect Formspree, FormSubmit, or another form service.
